### About This Webapp

This webapp was created to share details about our wedding as well as track critical information about our guests. It is built with HTML, CSS, and JavaScript, and is deployed using Netlify.

### How to Launch

1. **Clone the repository:**
  ```sh
  git clone https://github.com/zymoncone/wedding.git
  ```
2. **Navigate to the project directory:**
  ```sh
  cd wedding
  ```
3. **Install the dependencies:**
  ```sh
  npm install
  ```
4. **Start the development server:**
  ```sh
  npm run start
  ```
